## Fitur

- Matikan Copilot, Recall, dan integrasi AI lewat Registry
- Cegah paket AI terpasang ulang oleh Windows Update
- Matikan kebijakan Copilot
- Hapus paket Appx AI (Copilot, AIX, CoreAI, WindowsWorkload)
- Hapus fitur Recall dan tugas terjadwalnya
- Hapus paket AI tersembunyi (CBS)
- Bersihkan file AI dari sistem
- Sembunyikan komponen AI di Pengaturan
- Matikan Rewrite AI di Notepad
- Pasang aplikasi klasik: Notepad, Paint, Snipping Tool, Photo Viewer, Photos Legacy
- Mode Revert untuk mengembalikan perubahan
- Mode Backup untuk membuat titik pemulihan
- Tampilan modern dengan log proses langsung di jendela

## Cara pakai

1. Ekstrak seluruh isi zip (jangan jalankan langsung dari dalam zip).
2. Klik dua kali `Remove Windows AI bay Mekatik.exe`, pilih **Run as administrator**.
3. Pilih opsi, lalu klik **Terapkan**.

Butuh Windows PowerShell 5.1 (bawaan Windows). Buat restore point sebelum menjalankan.
